# Online Code Editor
design a system for an online code editor, similar to CodePen or JSFiddle. This editor should allow users to write, run, and share code snippets in various programming languages. It should also support features like syntax highlighting, code completion, and collaboration. How would you approach the design of such a system?

## Functional Requirements
- Code Writing
- Code Execution & Compiler
- Code Sharing
- Collaboration
- Syntax Highlight
- Code Completion
- User
    - Primary User
    - Secondary User

## Non-functional Requirements
- Scalability
- Extensible
- Modular
- PErformance
